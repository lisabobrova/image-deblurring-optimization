# Image Deblurring with Numerical Optimization

This project investigates image deblurring as an optimization problem and implements numerical methods for recovering an image from blurred observations.

The notebook constructs the required discrete operators and applies variational optimization techniques to the reconstruction problem. Primal-dual optimization and ADMM are implemented and used to compare reconstructed images under different parameter choices.

## Topics

* Image deblurring
* Variational optimization
* Primal-dual methods
* ADMM
* Discrete gradient operators
* Regularization
* Numerical linear algebra
* Image processing
